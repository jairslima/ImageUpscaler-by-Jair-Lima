# ImageUpscaler-by-Jair-Lima

## Descrição
Interface gráfica para ampliar imagens com IA (Real-ESRGAN via Upscayl NCNN), com arrastar e soltar.

## Stack
Python 3, Tkinter, tkinterdnd2, Pillow; engine upscayl-bin (baixado no setup).

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`setup.bat && python upscaler_gui.py`

## Estado atual
Versão pública inicial (2026-10-17), extraída do projeto original do autor.

## Problemas conhecidos
Testado apenas no Windows.
